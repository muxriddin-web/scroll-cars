
# 🚗 Lamborghini Centenario 3D Experience

Lamborghini Centenario 3D Experience is a modern front-end project created to showcase an interactive 3D automotive experience. The project combines a detailed 3D Lamborghini model with scroll-based animations, cinematic visuals, and a premium automotive-inspired interface.

Users can explore the vehicle by scrolling through the page, rotate the car around different angles, and experience a smooth transition from the exterior to the interior of the vehicle.

## ✨ Features

### 🚗 Interactive 3D Car Model

Explore a detailed Lamborghini Centenario 3D model integrated into the web experience.

### 🔄 180° Car Rotation

Scroll through the page to rotate the vehicle and explore its exterior from different angles.

### 🏎️ Interior View

Continue scrolling to transition from the exterior presentation and reveal the interior of the vehicle.

### ⏳ Loading Animation

A dedicated loading screen appears while the required 3D assets and page elements are being prepared.

### 🖱️ Scroll-Based Animation

The main vehicle animation is controlled by the user's scrolling, creating a smooth and immersive presentation.

### 🎬 Cinematic Design

The interface features a premium automotive-inspired design with:

- Dark cinematic background
- Modern typography
- Smooth animations
- Minimal interface
- High-contrast visual elements
- Premium automotive aesthetics

### ⚡ Smooth Performance

Optimized front-end code provides smooth transitions and responsive interactions throughout the experience.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/muxriddin-web/lamborghini-3d.git
```

### Navigate into the Project

```bash
cd lamborghini-3d
```

### Run the Project

Simply open:

```text
index.html
```

in your preferred web browser.

No complex installation or server-side setup is required.

## 🎮 How It Works

| Action | Description |
|--------|-------------|
| 🖱️ Scroll Down | Progress through the 3D experience |
| 🔄 Continue Scrolling | Rotates the vehicle through different angles |
| 🚗 Exterior View | Explore the vehicle from different perspectives |
| 🏎️ Interior View | Reveal the interior of the vehicle |
| ⏳ Loading Screen | Prepares the experience before the main page appears |
